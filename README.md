# tablet.ears.cat

tablet.ears.cat is a browser-based firmware patcher and configurator for drawing tablets. it installs, restores, and configures supported firmware directly over webusb/webhid.

## supported

- model: gaomon s620 and gaomon s620-16k
- most/all firmwares (if you have issues flashing, update FW)
- video installation tutorial provided on-site
- raises polling rate to up to 550hz, bypassing onboard jitter
- browser: desktop chromium with webusb + webhid
