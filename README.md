# tablet.ears.cat

firmware patch for gaomon s620

## supported

- model: gaomon s620
- stock firmware: `OEM02_T18e_241030`
- normal usb: `256C:006F`
- dfu usb: `28E9:0189`
- decoded stock application sha-256: `e4fe509d60c40468f7babe52341de59061266d6956e6f87c619112bd075550dd`

## experimental

The 16K-pressure S620 revision is under isolated bring-up at `/experimental` on the `port/s620-16k` branch. It is not registered in the production adapter list and the main installer does not expose it.
